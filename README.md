myRT - Digital Neighborhood Management System

A formal digitalization platform for RT/RW neighborhood units, featuring a community dashboard for citizen engagement. The app enables residents to submit letters/requests to village offices, report incidents, and share news/documentation. Admin (RT leaders) can manage submissions while maintaining transparency through public news feeds. Private requests remain confidential per user.

Built with Flutter, focusing on professional UI/UX with modern, clean, and lightweight design. Currently developing initial screens with authentication functionality. The system aims to bridge communication between residents and neighborhood leaders through transparent digital services.

Features:
- Digital letter requests to village offices
- Incident reporting with media upload
- Public news dashboard (transparent community updates)
- Private user requests (confidential)
- Admin dashboard for RT leaders
- Modern Flutter UI with professional styling

myRT - Sistem Manajemen Lingkungan Digital

Platform digitalisasi formal untuk unit lingkungan RT/RW, menampilkan dashboard komunitas untuk keterlibatan warga. Aplikasi ini memungkinkan warga mengajukan surat/permohonan ke kantor desa, melaporkan kejadian, dan berbagi berita/dokumentasi. Admin (ketua RT) dapat mengelola pengajuan sambil menjaga transparansi melalui feed berita publik. Permohonan pribadi tetap rahasia per pengguna.

Dibangun dengan Flutter, berfokus pada UI/UX profesional dengan desain modern, bersih, dan ringan. Saat ini mengembangkan layar awal dengan fungsionalitas autentikasi. Sistem bertujuan menjembatani komunikasi antara warga dan pengurus lingkungan melalui layanan digital yang transparan.

Fitur:
- Pengajuan surat digital ke kantor desa
- Pelaporan kejadian dengan upload media
- Dashboard berita publik (update komunitas transparan)
- Permohonan pengguna pribadi (rahasia)
- Dashboard admin untuk ketua RT
- UI Flutter modern dengan stylis profesional
